# Personal Portfolio Website

This is the repository for my personal portfolio website, built using HTML, CSS, and Vanilla JavaScript. 

It highlights my academic focus in engineering, projects related to automotive traction accumulators, and my experience with CFD (ANSYS Fluent) and computational tooling (MATLAB, Python).

## Local Development
To run this website locally, simply clone the repository and open `index.html` in your preferred web browser. No build steps or package managers are required.
